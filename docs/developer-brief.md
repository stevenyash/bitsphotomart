POST /api/auth/reset-password

GET /api/auth/verify-email/:token

Users
GET /api/users/profile

PUT /api/users/profile

GET /api/users/:id (admin)

PUT /api/users/:id/status (admin)

Photographers
POST /api/photographers/apply

GET /api/photographers/pending (admin)

PUT /api/photographers/:id/verify (admin)

GET /api/photographers/:id/portfolio

PUT /api/photographers/availability

Media/Stock
GET /api/media (public, with filters)

GET /api/media/:id

POST /api/media/upload (photographer)

PUT /api/media/:id (photographer)

DELETE /api/media/:id

GET /api/media/pending (admin)

PUT /api/media/:id/approve (admin)

Service Requests
POST /api/requests (client)

GET /api/requests (client/photographer/admin)

GET /api/requests/:id

PUT /api/requests/:id

GET /api/requests/:id/bids

Bids
POST /api/bids (photographer)

GET /api/bids/:id

PUT /api/bids/:id/accept (client)

DELETE /api/bids/:id

Assignments
POST /api/assignments (from accepted bid)

GET /api/assignments/:id

PUT /api/assignments/:id/status

POST /api/assignments/:id/submit-work

Payments
POST /api/payments/create-intent

POST /api/payments/mpesa/stk-push

POST /api/webhooks/mpesa

POST /api/webhooks/stripe

POST /api/webhooks/paypal

GET /api/payments/history

POST /api/payments/withdraw (photographer)

POST /api/payments/payout (admin)

Blog
GET /api/blog/posts

GET /api/blog/posts/:slug

POST /api/blog/posts (admin)

PUT /api/blog/posts/:id (admin)

DELETE /api/blog/posts/:id (admin)
