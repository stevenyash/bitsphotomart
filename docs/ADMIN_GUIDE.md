## Dashboard Overview

When you log in as admin, you'll see:
- 📊 **Total Orders** - Daily/weekly/monthly sales
- 👥 **Total Users** - Registered users count
- 📸 **Total Photos** - Photos in gallery
- 💰 **Revenue** - Platform earnings
- ⭐ **Recent Activity** - Latest orders and actions

## User Management

### Managing Regular Users
1. Go to `/admin/users`
2. View all registered users
3. Actions available:
   - **View** - See user details
   - **Edit** - Update user information
   - **Block** - Suspend user access
   - **Delete** - Remove user account

### Managing Photographers
1. Go to `/admin/photographers`
2. View photographer profiles
3. Actions:
   - **Approve** - Accept new photographer applications
   - **Verify** - Mark as verified photographer
   - **Suspend** - Temporarily disable account
   - **View Portfolio** - See their photos

## Content Management

### Blog Management
1. Go to `/admin/blog`
2. Create new posts or edit existing ones
3. Add images, format text
4. Publish or save as draft

### Photo Moderation
1. Go to `/admin/photos`
2. Review uploaded photos
3. Actions:
   - **Approve** - Make visible in gallery
   - **Reject** - Remove with reason
   - **Feature** - Add to homepage

### Service Configuration
1. Go to `/admin/services`
2. Add/edit service offerings
3. Set pricing tiers
4. Configure availability

## Orders & Payments

### Processing Orders
1. Go to `/admin/orders`
2. View all orders
3. Filter by status:
   - Pending - Awaiting payment
   - Paid - Payment confirmed
   - Processing - Being prepared
   - Completed - Delivered
4. Update status as needed

### Managing Payouts
1. Go to `/admin/payouts`
2. View payout requests
3. Review photographer earnings
4. Process payments via M-Pesa/PayPal

### Viewing Finance
1. Go to `/admin/finance`
2. View revenue reports
3. Filter by date range
4. Export reports

## Superadmin Functions

> ⚠️ **Note**: These functions are only for Superadmin users

### Role Management
1. Go to `/admin/superadmin/roles`
2. Create new roles
3. Assign permissions to roles
4. Edit existing roles

### Permission Management
1. Go to `/admin/superadmin/permissions`
2. View all permissions
3. Assign permissions to users/roles
4. Reseed default permissions

### User Administration
1. Go to `/admin/superadmin/users`
2. Create new admin users
3. Assign roles
4. Manage permissions

### Activity Logs
1. Go to `/admin/superadmin/activity-logs`
2. View all system activities
3. Track user actions
4. Audit changes
